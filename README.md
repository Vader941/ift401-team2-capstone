# IFT 401 Team 2 Capstone

A team-developed stock trading simulation created for **IFT 401: Information Technology Capstone** at Arizona State University.

> [!IMPORTANT]
> This is an educational simulation. It does not execute real trades or provide financial advice.

## Project Status

The team is currently completing requirements, system design, and development planning. Application code will be added after the initial architecture and setup decisions are confirmed.

## Planned Technology Stack

| Area | Technology |
|---|---|
| Language | Python |
| Web framework | Django |
| Frontend | Django templates, HTML, CSS, Bootstrap, and limited JavaScript |
| Database access | Django ORM |
| Local database | SQLite |
| Hosted database | MySQL |
| Authentication | Django authentication |
| Testing | Django test framework |
| Deployment | PythonAnywhere |
| Collaboration | GitHub |

The stack is the team's current baseline and may be revised if a documented project requirement or technical constraint makes a change necessary.

## Collaboration Workflow

New collaborators should begin with the **[First GitHub Collaboration Exercise](docs/first-github-collaboration-exercise.md)**.

1. Synchronize your local copy of `main`.
2. Create a short-lived branch for one task.
3. Commit focused changes with a clear message.
4. Push the branch and open a pull request into `main`.
5. Have another team member review the pull request.
6. Merge only after review and required checks pass.

Do not commit directly to `main`. See [CONTRIBUTING.md](CONTRIBUTING.md) for naming conventions and the complete workflow.

## Local Setup

Detailed setup commands will be added when the Django project is initialized. The expected workflow will be:

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies from `requirements.txt`.
4. Copy `.env.example` to `.env`.
5. Apply database migrations.
6. Start the Django development server.

Never commit `.env`, credentials, API keys, database exports, or real user information.
